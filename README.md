# C++ Programming Basics 🛠️

## Project Overview
This repository contains my personal practice files as I master **C++** and **Object-Oriented Programming**. These exercises focus on logic, syntax, statements and operators for my path in **Embedded Systems**.

## What's Inside?
* **Concepts:** statments, operators and Data Types.
* **Problem Solving:** Solutions to section challenges and logic puzzles.
* **Hardware Prep:** Experiments with timing and conditional logic that will eventually be used in firmware.

## How to Run
1. Clone the repo.
2. Compile using `g++` (e.g., `g++ main.cpp -o main`).
3. Run the executable (e.g., `./main`).
